자동 저장 — GitHub 연결

연결 안 됨

연결해 두면 글을 고친 뒤 몇 초 안에 GitHub 저장소의 index.html이 자동으로 바뀌고, 1~2분 뒤 홈페이지에 반영됩니다. 토큰은 이 브라우저에만 저장되고 홈페이지 파일에는 절대 들어가지 않습니다. 토큰 만드는 방법은 가이드 7장에 있습니다.

다른 방법 · 관리

토큰 없이 쓸 때는 "파일로 내려받기"로 받은 index.html을 GitHub 저장소에 올려서(덮어쓰기) 반영합니다. 고친 내용은 이 브라우저에도 임시 저장되어, 다음에 인증하면 이어서 할 수 있습니다.
